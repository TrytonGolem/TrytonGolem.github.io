Brand new page!

It's time to move on from my old page and create a brand new portfolio...

And here it is!

I decided to finally update my old, outdated portfolio page which was created with a boilerplate called getskeleton.

So, when creating a brand new portofolio, a new question arrived:

How do I create a brand new portfolio?

I mean I already created a website for my theatre teatrantrakt.pl and I created it (with my brothers help). The thing is that this website was created using a static site generator called hugo. It's a very good system that allows to create websites using created themes and editing only using markdown. No HTML or CSS knowledge required! But it stills requires markdown knowledge and using a seperate file editor such VS Code, Zed or a regular notepad. It's not ideal for long term or fast paced changing of data on the site.

The switch

I never really liked any of the CMS. The thought of using WordPress always makes me wanna puke. I tried joomla and drupal and while slightly better than WordPress they're still a mess. Then thanks to my brother I discovered a brand new player: Publii.

Thanks to Publii I was literally able to create an archeolgist webiste for my friend within 4-6 hours. I never had such an ease of creating a website and coming back to it to edit the information.

Conclusion

So, here we are! On my brand new portolio page using Publli.
